# Triangle Healthy Kitchen Design System Source

This folder stores the shared design-system reference for future UI work.

The current app is plain HTML/CSS/JavaScript, so these files are documentation and token references first. If the app is migrated later, these folders can become real reusable components.

Always read:

- `DESIGN_SYSTEM.md`
- `AGENTS.md`
- This folder

before creating or modifying UI.
