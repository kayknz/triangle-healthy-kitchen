# Triangle Healthy Kitchen (THK) — App Overview & Analysis

This document provides a comprehensive view of the Triangle Healthy Kitchen platform, detailing its features, ecosystem, and technical architecture.

## 🌟 The Vision
Triangle Healthy Kitchen is a **premium, end-to-end healthy lifestyle platform** tailored for the Qatari market. It transcends simple food delivery, functioning as a complete health-tech ecosystem that connects high-end culinary production with data-driven wellness.

---

## 🚀 Key Feature Categories

### 1. Three-Tier User Ecosystem
The platform is uniquely architected to serve three distinct groups within a single integrated system:
*   **Subscribers:** A personalized hub for health tracking, meal selection, and subscription management.
*   **Providers (Admins/Chefs):** A sophisticated "Command Center" for menu engineering, kitchen logistics, and subscriber oversight.
*   **Riders:** A streamlined mobile interface for delivery tracking, route management, and real-time status updates.

### 2. Intelligent Meal Management
*   **Chef-Crafted Subscription Plans:** Users can choose from goal-oriented packages (Weight Loss, Muscle Gain, Wellness).
*   **Dynamic Menu Rotation:** A robust system that manages high-quality, nutritionally balanced menus that refresh periodically.
*   **Guided Booking Flow:** A seamless, multi-step process for one-time bookings or recurring plan sign-ups.

### 3. Health & Personalization
*   **Nutritional Transparency:** Full breakdown of calories and macros (Protein, Carbs, Fats) via the `HealthTab`.
*   **Onboarding IQ:** A health-profiling engine that gathers user data to ensure meal plans align with specific dietary goals.
*   **Progress Tracking:** Built-in tools for subscribers to monitor their physical transformation over time.

### 4. Global Logistics & Payments
*   **Multi-Gateway Integration:** Supports local and international transactions via **Tap Payments**, **Stripe**, and **Dibsy**.
*   **Native Geolocation:** Leverages device GPS for precise delivery management and rider efficiency.

---

## 🛠️ Technical Architecture
The app is built on a modern, high-performance stack designed for stability and scale:
*   **Frontend:** React with TypeScript, using Tailwind CSS for a premium UI.
*   **Mobile Shell:** Capacitor JS, providing native access to device features (GPS, Status Bar, Splash Screen).
*   **Backend:** Supabase (PostgreSQL) for real-time data sync, secure authentication, and database functions.
*   **Localization:** Deeply integrated bilingual support (Arabic & English).
